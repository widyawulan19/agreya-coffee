# ☕ Dekultur Digital Menu

A modern digital menu concept for **Dekultur Coffee**, designed to provide customers with a clean, mobile-friendly, and interactive browsing experience.

Instead of relying on static PDF menus or printed posters, this project presents the menu in a responsive web interface with intuitive navigation, category-based browsing, and recommendation sections.

---

## ✨ Features

- 📱 Mobile-first interface
- ☕ Browse menu by category
- 🍰 Dedicated category detail pages
- ⭐ Recommendation page (Barista Picks & Guest Favorites)
- 🏠 About page with café information
- 🎨 Clean and modern UI inspired by café branding
- ⚡ Built with reusable React components
- 🖼 Smooth image loading with reusable image loader
- 🎭 Lightweight animations for a more engaging experience

---

## 📄 Pages

### Welcome
A clean landing page introducing the café and inviting visitors to explore the menu.

### Category
Displays all available menu categories with visual previews.

### Category Detail
Shows menu items within a selected category, including:

- Menu name
- Price (Medium & Large)
- Best Seller highlight
- Category description

### Recommendation
Highlights curated selections, including:

- Barista Picks
- Guest Favorites

### About
Provides essential café information, including:

- Opening hours
- Contact information
- Location
- Social media

## 📦 Installation

Clone this repository

```bash
git clone https://github.com/yourusername/dekultur-digital-menu.git
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
